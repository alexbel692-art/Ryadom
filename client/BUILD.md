# Сборка клиента «Рядом»

Клиент собирается прямо в этом репозитории через GitHub Actions. Это RustDesk с нашим названием, иконкой
и вшитым сервером. Ставить на компьютер ничего не нужно. Для публичного репозитория сборка бесплатна.

## Что где лежит

| Файл | Что в нём |
|---|---|
| `client/server.json` | **адрес сервера, открытый ключ, API**: вшиваются в клиент |
| `client/ryadom.json` | название, язык, разрешения, способ принятия подключений |
| `client/icon.png`, `client/logo.png` | иконка (1024×1024) и логотип в окне программы |
| `.github/workflows/generator-*.yml` | сборка для Windows / macOS / Linux / Android (на основе [rdgen](https://github.com/bryangerlach/rdgen), GPL-3.0) |

## Собрать

1. В `client/server.json` впишите домен сервера в `host` и `api` (`https://домен`).
   Если ключ сервера генерировали не вы сами, а hbbs при установке, впишите его в `key`: это содержимое `server/data/id_ed25519.pub`.
2. На GitHub: вкладка **Actions** → слева выберите платформу:
   - **Custom Windows Client Generator** → `Ryadom.exe` и `Ryadom.msi`
   - **Custom macOS Client Generator** → `Ryadom-aarch64.dmg` (M1/M2/M3) и `Ryadom-x86_64.dmg` (Intel)
   - **Custom Linux Client Generator** → `.deb`, `.rpm`, `.AppImage`, `.flatpak`
   - **Custom Android Client Generator** → `.apk`
3. Нажмите **Run workflow** → **Run workflow** (поля менять не нужно).
4. Через 30–60 минут откройте завершённый запуск. Внизу, в разделе **Artifacts**, лежат готовые файлы (zip).
5. Распакуйте и положите на сервер в `server/downloads/`: файлы сразу появятся на странице загрузки.

## Подпись Android

Без подписи APK не установится на телефон. Один раз добавьте в **Settings → Secrets and variables → Actions →
New repository secret** четыре секрета из файла `android-secrets.txt` (его выдали вместе с ключом):
`ANDROID_SIGNING_KEY`, `ANDROID_ALIAS`, `ANDROID_KEY_STORE_PASSWORD`, `ANDROID_KEY_PASSWORD`.
Храните `ryadom-android.jks` и пароль: без них обновление не встанет поверх установленного приложения.

## Ключ сервера

Клиент доверяет только серверу с ключом из `client/server.json`. Пара ключей сгенерирована заранее:
- открытый ключ уже в `client/server.json`;
- закрытый — файл `id_ed25519`. **В репозиторий его не класть.** Перед `install.sh` скопируйте его в папку `server/`
  на VPS: установщик перенесёт его в `server/data/`.

Если ключ потерян или сервер переустановлен с новым ключом, впишите новый открытый ключ в `server.json` и пересоберите клиенты.

## Особенности платформ

- **Windows**: файл без цифровой подписи, SmartScreen покажет предупреждение («Подробнее → Выполнить в любом случае»).
  При установке появляется служба: через неё работает подключение к экрану входа и UAC.
- **macOS**: не подписано Apple. Первый запуск: правый клик → «Открыть». Затем дайте разрешения «Запись экрана» и «Универсальный доступ».
- **Android**: разрешите установку из неизвестных источников. Для управления телефоном включите службу специальных возможностей программы.
- **iOS**: Apple не даёт сторонним программам управлять iPhone. С iPhone подключаются стандартным RustDesk из App Store,
  указав наш сервер (параметры есть в панели, раздел «Подключение»).
